# XenRaft

A simple XenRaft Engine for Low Latency.

With XenRaft, you get a lightweight tool that stays out of your way.

**What you get**

- A simple XenRaft Engine for Low Latency

## Key Features

- A simple XenRaft Engine for Low Latency

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/XenRaft.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
